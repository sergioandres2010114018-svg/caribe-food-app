# CaribeFood App 🌴🐟
**“El sabor del Caribe en tu cocina”**

Aplicación móvil (Flutter) para recopilar, organizar y divulgar las recetas tradicionales del
Caribe colombiano, con **fotos y videos** guardados en una base de datos en línea (Supabase).

Proyecto productivo SENA — Técnico en Programación de Aplicaciones para Dispositivos Móviles ·
Institución Educativa Técnica Departamental Pijiño del Carmen (Magdalena) · Grupo 3321831.

## Funciones
- Inicio con receta del día y categorías
- Catálogo por categorías: pescados, arroces, sopas, fritos, dulces y bebidas
- Búsqueda por plato o ingrediente (sin importar tildes)
- Detalle: ingredientes con casillas, pasos numerados, historia cultural, galería de fotos y videos
- Favoritos guardados en el teléfono
- Sección de cultura gastronómica del Caribe
- Zona del equipo: iniciar sesión y subir recetas, fotos (galería o cámara) y videos
- Funciona sin conexión con la última copia descargada
